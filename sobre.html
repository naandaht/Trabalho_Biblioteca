📌 Sobre a biblioteca

Este sistema foi desenvolvido como um exemplo de aplicação com HTML, CSS e JavaScript. Possui 3 páginas interligadas, com navegação e validações simples.

  • 📚 Livros — lista estática de títulos.
  • ✍️ Cadastro — formulário com validação (campos obrigatórios).
  • ℹ️ Sobre — informações do projeto.

🔹 Nenhum dado é armazenado (sem localStorage, banco ou cookies).
